Política de privacidad de gog-openclaw

Última actualización: 24 de octubre de 2026.

  • Quién la usa: solo su propietario. No hay otros usuarios.
  • Qué datos trata: correo, calendario, contactos y archivos de Google Drive, Docs y Sheets de la cuenta del propietario, únicamente cuando él lo pide a su asistente personal.
  • Dónde se guardan: el token de acceso se guarda cifrado en un servidor privado del propietario. Los datos no se almacenan fuera de ese servidor salvo lo necesario para responder a sus peticiones.
  • Con quién se comparten: con nadie. No se venden ni se ceden a terceros, ni se usan para publicidad.
  • Revocar el acceso: en cualquier momento desde myaccount.google.com/permissions.

El uso de los datos recibidos de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
